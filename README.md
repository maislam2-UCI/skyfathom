# NightSky

Night-sky map + astrophotography planner PWA for Android. Zero dependencies.

```
npm run dev      # http://localhost:4321  (LAN URL printed for phone testing)
npm test         # node --test
npm run catalog  # regenerate data/catalogs (not implemented yet)
```

See `CLAUDE.md` for the brief and `docs/PLAN.md` for the feature matrix and phases.
